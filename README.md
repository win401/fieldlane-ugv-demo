# FIELDLANE · 관수 운영 시뮬레이터

가상 과수원의 관수 작업을 연습하는 독립 예제입니다. 실제 좌표, 외부 지도, 회사 자산, 로그인, 장비 명령, DB 연동은 없습니다. 모든 장비와 수분 값은 예제에서 정의한 가상 데이터입니다.

## 로컬에서 열기

Node.js 20 이상에서 아래 명령 하나로 시작합니다. 패키지 설치나 환경 파일이 필요하지 않습니다.

```sh
npm start
```

[http://127.0.0.1:4173](http://127.0.0.1:4173)에서 확인합니다. 종료는 Ctrl+C입니다. 이미 포트가 사용 중이면 `PORT=4174 npm start`처럼 다른 번호를 지정합니다.

1. 개념도에서 구역을 클릭하거나 드롭다운으로 고릅니다.
2. 모의 장비 상태·배터리·물탱크를 확인하고 1~30분짜리 작업을 추가합니다. 충전 중인 장비와 이미 열린 작업이 있는 장비는 배정하지 않습니다.
3. 이력에서 대기 작업을 시작한 다음 완료 또는 취소합니다. 시작은 상태를 바꾸는 시연이며, 타이머나 실제 장비 제어가 아닙니다.
4. 상태를 필터링하거나 새로고침해서 저장 여부를 확인합니다. 기록은 같은 브라우저·주소의 localStorage에 남고 공유되지 않습니다.

```sh
npm test
```

검증 범위: 입력·중복 배정, 상태 전이, 로컬 기록 복구, HTTP 자산·상태 점검. 서버는 외부 서비스에 요청하지 않습니다.

## LINKSPACE를 보여주는 예제로 쓰려면

이 프로젝트는 별도의 Git 저장소에 처음부터 구성한 시뮬레이터입니다. Cloud Run이나 LINKSPACE는 아직 연결하지 않았습니다. 아래 단계는 나중에 읽기 전용으로 연결할 때 참고할 수 있습니다.

1. 가령 가상 구역 이름을 바꾸는 작은 PR을 만들면 GitHub Actions의 Demo checks 워크플로가 `npm test`를 실행합니다.
2. 별도로 승인한 환경에 배포한 경우, 다음 revision의 상태 점검은 `GET /health`에서 확인할 수 있습니다. Cloud Run 같은 컨테이너 환경에서는 플랫폼이 제공하는 `PORT`를 받고 `HOST=0.0.0.0`으로 바인딩해야 합니다. 이 예제는 외부 DB, 지도 키, 장비 자격증명을 요구하지 않습니다.
3. LINKSPACE에는 새 저장소와 승인된 배포 환경의 정보를 읽기 전용으로 연결하고, PR과 CI 실행 결과, 배포 상태가 각각 표시되는지 확인합니다. 이 코드는 LINKSPACE 본체나 연결 도구가 아닙니다.
